# Onest

Self-hosted variable Onest, weights 100–900, normal style. Latin and LatinExt
subsets cover Polish characters. The same font family is used on lemric.com
and dataleaktracker.org; these WOFF2 assets were copied from the local
DataLeakTracker project.
